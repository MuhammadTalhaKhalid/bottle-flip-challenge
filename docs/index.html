How to play
1. Pick a time (15/30/45/60s) and tap Start Challenge.
2. Hold the phone low, bottle in view (low angle = most accurate).
3. Flip! A good landing = bottle upright & still.
4. Flip as many as you can before the timer hits 0 — beat your high score 🏆

YOLOv8n bottle detection + MobileNetV3 temporal landing classifier (99.3% val accuracy), running entirely in your browser via ONNX Runtime Web. Nothing is uploaded.
